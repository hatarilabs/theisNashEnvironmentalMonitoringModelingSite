\section{Introduction}
This document outlines the workflow for conducting a 2D unsteady flow (dynamic) simulation in HEC-RAS using a topobathymetric GeoTIFF and known water surface elevations (heads).

\section{Part 1: Setting Up the Terrain}
Before performing hydraulic calculations, HEC-RAS requires a Digital Elevation Model (DEM) in a specific format (.hdf).

\subsection{Open HEC-RAS:} 
Create a new project.

\section{Save and upload geometry}

Stop editing the geometry and then Rasmapper data save under File / Save.

Also save the geometry under Save Geometry As... The geometry name is River_Base

Open the saved geometry. The geometry should appear in the Geometric Data window and the path should appear on the HEC RAS project.

\section{Part 4: Simulation of unsteady flow}

From the main HEC-RAS window, go to Edit → Unsteady Flow Data

\subsection{Set Up Boundary Conditions}
Click on the Boundary Conditions tab. You should see your boundary condition lines listed (from your geometry)
Click on the upstream boundary condition line to select it. In the dropdown, choose Stage Hydrograph
